# Enchanted Excavation

Enchanted Excavation is a Minecraft plugin that adds enchantments to your tools when you mine specific blocks. This plugin is designed to enhance the mining experience by providing players with unique enchantments when they break certain blocks, such as dirt. The plugin is built using the PaperMC API and is compatible with Minecraft version 1.21.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server to load the plugin.

## Use

1. Start your Minecraft server with the plugin installed.
2. Mine dirt blocks with a diamond pickaxe to receive enchantments on your tool.
3. Enjoy the enhanced mining experience with your newly enchanted tools.
